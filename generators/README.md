# generators/

Deterministic project generators (spec §4.3), seedable sizes S/M/L. **Empty in this pass** —
`projects/android` and `projects/node` are hand-written fixture projects instead (see `CLAUDE.md`
"Known deviations"). Add a generator here (e.g. `android.py`) when a stack needs size-scaled sample
projects (relevant once `SHOWCASE_PROJECT_SIZE` / cost considerations, spec §12.4, matter).
