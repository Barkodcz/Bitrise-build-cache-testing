# projects/ios

Real XcodeGen-generated single-target SwiftUI app used by the Build Cache for Xcode scenarios
(`scenarios/catalog.yml` `IOS-*`). `project.yml` is the committed source of truth — the generated
`ShowcaseiOS.xcodeproj` is never committed (regenerated by `xcodegen generate` as the first step of
every `IOS-*` scenario, per spec §4.3).

- `Sources/Core.swift` — a "widely depended" file; every other source file is compiled as part of
  the same module.
- `Sources/Leaf.swift` — mutated by `tools/simulate-change.sh ios leaf`.
- `Sources/App.swift` — the `@main` SwiftUI entry point.

Builds target the iOS Simulator only (`CODE_SIGNING_ALLOWED=NO`) — no code signing, no real Apple
Developer account needed. Verified locally: `xcodebuild build -project ShowcaseiOS.xcodeproj
-scheme ShowcaseiOS -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO` succeeds
end-to-end with a plain `xcodegen generate` beforehand.
